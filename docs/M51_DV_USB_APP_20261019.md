## Bukti yang berbeda

- [Handoff pengguna](decisions/DV_USB_NATIVE_HANDOFF_20261019.md): program native
  USBFS/root mengirim100byte, kertas sempurna dilaporkan pengguna. Itu bukti jalur
  native, bukan aplikasi. Tool native tersebut tidak dijadikan dependency produksi.
- Pemeriksaan agent: Android USB Host Framework mengenali tepat satu PYN-58L,
  VID0483/PID5720, interface0/alt0/class7/subclass1/protocol2, BULK_OUT01 dan
  BULK_IN81, packet64. Serial USB001 generik tetap identitas attachment sementara;
  tidak di-hardcode sebagai identitas persisten. Node USB juga tidak di-hardcode.
- **Adapter aplikasi berhasil mengirim81/81byte**, satu write, satu target;
  native integration test1PASS00:04. Menggunakan `NativePrinterTransport`,
  `PrinterUsb` dan output gate produksi dalam package terisolasi
  `com.example.kasir_app.integration`, bukan checkout atau pencetakan kode recovery.
- **Kertas cetakan aplikasi: PASS DILAPORKAN PENGGUNA.** Pengguna menjawab “ya”
  pada pemeriksaan lima baris cetakan baru, lengkap/terbaca/tidak terpotong. Tidak mengubah byte
  accepted menjadi PASS paper. Tidak ada pengiriman ulang otomatis.
