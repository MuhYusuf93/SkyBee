# M5.1 — uji USB printer melalui PC, 19 Oktober 2026

Pengguna mengizinkan tes cetak PC karena Poco dan printer berbagi kabel.
Pemeriksaan read-only Windows menemukan PYN-58L, VID0483/PID5720,
USB Class07/Subclass01/Protocol02, service usbprint dan problemCode0.
Tidak ada antrean printer Windows perangkat ini; tidak memasang driver,
menambah queue, mengubah default printer/registry/firmware atau pengaturan.

`tools/windows_usb_printer_probe.py` default read-only. SetupAPI memperoleh
interface USBPRINT yang hadir, memilih tepat instance perangkat yang diperiksa,
lalu satu pengiriman ESC/POS publik lewat handle driver bawaan. Tidak menebak
path/port atau mengirim ke perangkat lain. Marker eksklusif sebelum pengiriman
mencegah replay; proses write dibatasi12detik. Tidak retry hasil parsial/timeout.
Tidak mengirim perintah konfigurasi persisten, key recovery atau data penjualan.

Hasil otomatis: **81/81 byte diterima tanpa error Windows**, satu pengiriman.
Hasil manual **dilaporkan pengguna: PASS**, jawaban “ya” untuk kertas keluar,
teks jelas/lengkap/tidak terpotong:

```text
UJI USB PC M5.1
PYN-58L / USB DATA
1234567890
IDR 12.000
BUKAN TRANSAKSI
```

[Bukti publik tanpa rahasia](evidence/m51-20261019/usb-pc-public-result.json).
Marker/log privat di ignored `build/m51-usb-pc-public-20261019-01/` tetap
mencatat status sebelum laporan manual; laporan pengguna disimpan terpisah.

Ini membuktikan port data USB dan sampel ESC/POS pada perangkat yang tersambung
ke PC. Nama PYN-58L adalah descriptor USB, tidak mengganti nama firmware atau
identitas model. **Bukan bukti adapter/permission/USB Host Android atau cetak dari
aplikasi M5.1.** Adapter Android checkpoint F belum selesai. OTG, logo/struk
panjang, cabut kabel/partial-write dan kertas habis melalui Android NOT TESTED.
Tidak memaksa uji USB pada DV8910. Poco belum ADB karena kabel dipakai printer;
pengguna akan mencari kabel tambahan nanti, tanpa mengubah konfigurasi HP.

Dasar API: [Microsoft USB printer driver](https://learn.microsoft.com/en-us/windows-hardware/drivers/print/usb-printing),
[SetupDiGetDeviceInterfaceDetailW](https://learn.microsoft.com/en-us/windows/win32/api/setupapi/nf-setupapi-setupdigetdeviceinterfacedetailw).
Driver USBPRINT menyediakan jalur komunikasi, bukan jaminan rendering/paper;
keberhasilan kertas diperoleh dari pemeriksaan pengguna di atas.
