## Kriteria sebelum rollout

Prototype/screen dapat ditinjau sebelum redesign luas. Gunakan data sintetis,
tanpa screenshot data toko nyata. Perubahan presentasi tidak mengubah kontrak
uang/HPP/stok/otorisasi/backup, snapshot historis atau menambah hambatan kasir
tanpa keputusan pengguna. Uji layar sempit/lebar, ID/EN, text scale dan TalkBack
sesuai ketersediaan; hasil fisik tidak diasumsikan dari widget tests.

M6 tetap rilis/legal/identitas/Play setelah M5.1 dan keputusan/pengerjaan UI yang
dipilih pengguna. Dokumen ini tidak menetapkan desain final.
