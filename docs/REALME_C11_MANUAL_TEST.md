# Langkah manual Realme C11 pada paket uji

Konvensi jawaban pengguna, disepakati16Oktober2026: **"ya" berarti semua hasil yang diharapkan pada langkah aktif terakhir sesuai**; bila berbeda pengguna akan menjelaskan. Catat sebagai manual dilaporkan pengguna hanya untuk langkah tersebut. Jangan meminta ulang rincian yang sudah tercakup tanpa ambiguitas baru.

Jalankan setelah runner otomatis selesai dan paket uji disiapkan. Package harus `com.example.kasir_app.integration` (label kasir_app tests); semua barang/pelanggan sintetis. Paket akhir membuka kasir asli langsung. PIN fixture publik **0001**; produk **Realme C11 fixture goods**, barcode **000123**, isi dus40. Jam fixture berada pada Oktober2026 dan bertambah normal untuk undo/sesi; pengaturan jam Android tetap. Bukti manual dicatat hanya setelah pengguna mengirim hasil/skala/metode, terpisah dari synthetic Flutter/ADB. Jangan mengirim PIN pribadi/token atau screenshot keyboard yang berisi saran pribadi.

1. Buka kasir fixture. Ketik barcode000123 tiga kali memakai keyboard HP dengan Done/Enter. Periksa satu baris quantity3, toggle grosir mempertahankan satu baris, plus/minus/hapus/Urungkan tidak melampaui stok. Laporkan apakah keyboard tampil dan tombol yang digunakan.
2. Pada pembayaran sebagian, ketik nominal10000 dengan cepat. Hapus digit di tengah, pilih/ganti sebagian, lalu paste teks uji12000/12.000 (Indonesia) atau12,000 (English). Periksa nominal, caret, grouping, validasi dan sisa hutang. Batalkan dulu agar langkah input tidak dianggap transaksi selesai.
3. Ubah bahasa saat draft/form aktif. Isi tetap terjaga dan label/error sesuai bahasa; currency tidak berubah. Buka form Gudang setelah PIN fixture, scroll semua field dengan keyboard tampil, isi stok/restock dus5×40 dan periksa preview200; harga beli/dus120000 menghasilkan biaya600000. Jangan mengubah pengaturan sistem untuk mempercepat HP.
4. Tekan konfirmasi checkout cepat dua kali pada penjualan sintetis. Periksa receipt hanya satu dan stok berkurang sekali. Bayar piutang sebagian/penuh; laporan tidak menambah penjualan/HPP/laba saat pelunasan.
5. Masuk background lewat Home dan kembali; kunci/buka layar seperti biasa. Periksa PIN pengelolaan terkunci dan draft kasir pulih. Ini interaksi lockscreen/background, bukan reboot atau kehilangan daya.
6. TalkBack tersedia sebagai package pada preflight. Jika dapat diuji secara manual, catat apakah sebelumnya aktif, aktifkan melalui menu aksesibilitas biasa, lalu periksa label tombol, urutan fokus, total/error, input dan dialog. Pulihkan ke kondisi sebelumnya setelah selesai. Jika tidak dilakukan, status NOT TESTED; hadirnya package/semantics otomatis bukan PASS TalkBack.

Fontbesar2× sudah disimulasikan oleh fixture otomatis; pengaturan perangkat asli preflight1,0. Jika menguji ukuran font perangkat secara manual, catat nilai/skala aktual dan pulihkan1,0. Beri hasil per langkah: PASS/FAIL/belum dicoba, gejala, bahasa dan keyboard/TalkBack yang dipakai. Jangan menganggap langkah di atas lulus dari instruksi ini saja.
